Plate Redactor

Upload a batch of similarly-framed vehicle photos. Mark the plate on the first one, then hit "Match to all" — it finds that same patch in every other photo using local pattern matching, no need to mark each one by hand. Fine-tune any that miss, then blur or black out and download. Everything runs locally in your browser; nothing is uploaded anywhere.

Click to choose images, or drop them here JPG or PNG · multiple files supported · works entirely offline in this tab

Auto-detect on upload is a whole-image best guess and can miss. For a batch of similar photos (same camera angle/setup), the reliable route is: fix the box on one image, click 📌 Set as template, then ▶ Match to all images — it searches for that same visual patch in each other photo. Drag a box to reposition, drag the corner dot to resize, double-click a box to remove it.

OCR reads the text inside the box and checks it against real Indian state codes (DL, MH, KA, ...) to filter out noise — a green check means it found a valid state-code pattern; still worth a quick eyeball since misreads happen. First read loads the OCR engine, which can take a few seconds.

Processing is done locally on your device using the Canvas API. No images leave your browser.
